# SHEGCOMTECH brand assets

Upload the original SHEGCOMTECH logo into this folder.

## Recommended upload
- Preferred filename: `logo.svg` for a vector logo, or `logo.png` for a transparent raster logo.
- Keep the original artwork unchanged; do not screenshot it or place it inside another image.
- If you have light and dark versions, upload both and name them clearly, for example `logo-light.svg` and `logo-dark.svg`.

Once uploaded, the logo can be reviewed and then wired into the storefront and admin interface where appropriate.
